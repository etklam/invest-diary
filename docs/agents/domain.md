# Domain docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root for canonical domain language.
- Read the relevant ADRs under `docs/adr/` before changing an affected area.
- If either source is absent, proceed without creating placeholder documentation.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issue titles, implementation plans, hypotheses, tests, and user-facing copy. Avoid synonyms that the glossary explicitly rejects.

If a required concept is missing, reconsider whether existing language already covers it. Record a genuine domain-language gap for a later documentation discussion rather than silently inventing terminology.

## ADR conflicts

Surface any conflict with an existing ADR explicitly. Do not silently replace an accepted architectural decision.
