# ADR-0003: AI Agent 作為標準 User 帳號

## 決策

AI agent 夥伴使用與真人完全相同的 User 帳號和 PartnerLink 機制。Agent 擁有獨立的 User 記錄，透過 API key 認證（等同登入），與真人使用者建立雙向夥伴關係後，分享股票筆記和時間線記錄。路徑與真人完全一致，沒有任何特殊通道。

## 原因

領域模型中，AI agent 的角色是「資深市況分析師」——一個有獨立身份、獨立觀點的協作者。它不是你帳號的延伸，而是一個對等的夥伴。如果讓 agent 透過特殊權限直接寫入你的資料，會模糊「誰的觀點是誰的」這條界線。獨立帳號意味著：
- Agent 的 StockNote 明確標記來源為 agent，不是使用者
- 分享權限由雙方各自控制，不是單向寫入
- 未來可以有多個 agent 夥伴、agent 和真人混合的協作場景

## 取捨

- **選了**：Agent 作為獨立 User，使用與真人相同的身份和夥伴機制
- **沒選**：Agent 作為 User 帳號的延伸（API key 直接代理使用者寫入）——簡單但失去來源追溯和權限隔離
- **沒選**：單獨的 Bot/Service 身份模型——增加概念複雜度，且夥伴機制需要兩套邏輯
