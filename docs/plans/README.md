# Plans

Implementation plans are organized by status:

- `active/` — only work that is currently approved and underway
- `review-needed/` — older plans whose remaining items must be re-audited before implementation
- `../archive/completed/` — delivered plans retained as historical evidence
- `../archive/deprecated/` — superseded plans that must not be treated as current direction

There are currently no confirmed active plans in this directory. New product work is specified in the local Markdown issue tracker under `.scratch/<feature-slug>/` and moves here only when a durable implementation plan is useful.
