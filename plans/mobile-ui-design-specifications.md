# 行動裝置 UI 設計規範

## 設計原則

### 1. 行動優先 (Mobile First)
- 所有新功能以行動裝置體驗為主要設計考量
- 桌面版作為行動版的延伸，而非相反
- 確保核心功能在行動裝置上完整可用

### 2. 觸控友好 (Touch Friendly)
- 最小觸控目標：44px × 44px
- 重要操作按鈕：48px × 48px 或更大
- 按鈕間距至少 8px，避免誤觸

### 3. 視覺層次 (Visual Hierarchy)
- 重要資訊置頂，次要資訊可展開
- 使用大小、顏色、間距建立清晰的視覺層次
- 保持一致的設計語言

## 動畫規範

### 過渡動畫
- 標準過渡：0.3s ease-out
- 快速過渡：0.15s ease-out
- 緩慢過渡：0.5s ease-out

### 微互動
- 按鈕點擊：scale(0.95) → scale(1)
- 卡片懸停：elevation 2 → elevation 4
- 頁面切換：slide-in-right 0.3s

### 載入動畫
- 骨架屏：shimmer 1.5s infinite
- 轉圈：spin 1s linear infinite
- 脈衝：pulse 2s ease-in-out infinite

## 無障礙設計

### 觸控目標
- 最小尺寸：44px × 44px
- 推薦尺寸：48px × 48px
- 目標間距：至少 8px

### 色彩對比
- 正常文字：至少 4.5:1
- 大文字：至少 3:1
- 非文字元素：至少 3:1

### 焦點指示
- 焦點環：2px 實線
- 顏色：品牌色彩
- 偏移：2px

## 實作注意事項

### CSS 架構
- 使用 Tailwind CSS 工具類別
- 自定義元件類別遵循 BEM 命名規範
- 響應式設計使用 mobile-first 原則

### JavaScript 互動
- 使用 Vue 3 Composition API
- 事件處理考慮觸控和滑鼠事件
- 避免複雜的手勢，保持簡單直觀

### 效能考量
- 圖片使用 WebP 格式
- 動畫使用 CSS transform 和 opacity
- 避免過度的陰影和模糊效果
